# QA, 23 Σεπτεμβρίου 2026: ομάδες, εγγυημένη επιστροφή, export, ασφάλεια, σύνδεσμος

Χειροκίνητο πέρασμα στο Expo web build μέσω Chrome DevTools (CLI του
`chrome-devtools-mcp`, headless), με API σε DEV_MODE πάνω σε ξεχωριστή βάση `qa`
και τους τρεις χρήστες του `scripts/seed-demo.sh`. Δύο απομονωμένα browser
contexts: Γιώργος (οδηγός) και Νίκος (επιβάτης). Ένα τρίτο ανώνυμο για τον σύνδεσμο.

Πώς ξανατρέχει:

```bash
IP=127.0.0.1 API_PORT=8187 WEB_PORT=8197 DB=qa WEB_DIR=/tmp/carpool-web-qa scripts/dev-lan.sh
API=http://127.0.0.1:8187/v1 scripts/seed-demo.sh
```

Το `chrome-devtools-mcp` θέλει Node ≥ 22.12. Το `~/.local/opt/node` είναι 22.11 και ο
daemon πεθαίνει σιωπηλά. Τρέχει με `/usr/bin/node` (22.22).

## Ευρήματα

Όλα διορθώθηκαν στο ίδιο commit με αυτό το αρχείο. Τα F1, F2, F3 και F8
ξαναελέγχθηκαν στον browser μετά τη διόρθωση.

| # | Βαρύτητα | Τι | Διόρθωση |
|---|---|---|---|
| F1 | important | Σε desktop browser κάθε «Στείλε…» έβγαζε «Κάτι πήγε στραβά»: δεν υπάρχει `navigator.share` | `shareText`: αντιγραφή στο clipboard και «Αντιγράφηκε» |
| F2 | important | Αναζήτηση από σύνδεσμο ή πρόταση: οι θέσεις κρατιούνταν αλλά τα πεδία φαίνονταν άδεια | `PlaceField` συγχρονίζει το κείμενο με `value` που έρχεται μετά το mount |
| F3 | important | Φεύγοντας από τη σελίδα ενώ μοιράζεσαι θέση, η θέση έμενε στον server έως 1 ώρα | Αναμονή για το PUT που τρέχει πριν το DELETE, και `pagehide` + `keepalive` στο web |
| F4 | nit | «πριν 0′» | «τώρα» |
| F5 | nit | Κουμπιά export «2026-08» | «Αύγουστος 2026» |
| F6 | nit | Το `HEAD /r/{token}` απαντούσε 405, και δεν υπήρχαν og tags για προεπισκόπηση σε chat | HEAD + `og:title`/`og:description` |
| F7 | nit | Η οθόνη του συνδέσμου δείχνει «έχω 3 θέσεις» σε πρώτο πρόσωπο | Αφέθηκε: είναι το ίδιο μήνυμα που έστειλε ο οδηγός, αυτούσιο |
| F8 | important | Το `Alert.alert` δεν κάνει τίποτα στο web: ακύρωση ταξιδιού, απόσυρση, αποχώρηση και νέος κωδικός ήταν νεκρά κουμπιά | `confirm`: `window.confirm` στο web |
| F9 | important | Αίτημα χωρίς εναλλακτικές έγραφε «ρωτάμε ήδη τον επόμενο» ακριβώς πάνω από «δεν βρέθηκε άλλο αυτοκίνητο» | Η πρόταση εξαρτάται από το αν υπάρχει κάποιος να ρωτηθεί |

## Τι δεν καλύφθηκε

- Συσκευή: native share sheet, πραγματικό GPS, push. Όλα δοκιμάστηκαν στο web.
  Χρειάζεται ένα πέρασμα σε Android build.
- Η ζωντανή θέση στο web δοκιμάστηκε με ψεύτικο `navigator.geolocation`. Ο headless
  Chrome αρνείται την άδεια.
- Με ανοιχτό browser το export κατεβαίνει. Το περιεχόμενο του CSV το ελέγχουν τα
  Go tests, όχι αυτό το πέρασμα.
