# Data Model

PostgreSQL 16 + PostGIS 3.4. SRID 4326 everywhere; store both `geometry` (for
line-ordering ops) and rely on `geography` casts for metre-accurate distance.
All timestamps `timestamptz`; scheduling logic in `Europe/Athens`.

## Entity relationship overview

```
users ─1:0..1─ driver_profiles
users ─1:N─ push_tokens
regions ─1:N─ users (home_region)
driver_profiles ─1:N─ route_templates ─1:1─ route_schedules
route_templates ─1:N─ trip_occurrences ─1:N─ bookings ─N:1─ ride_requests
ride_requests ─1:N─ asks (sequential driver asks)
trip_occurrences ─1:N─ trip_messages
users ─1:N─ ratings (per completed booking)
outbox (standalone)
```

## Tables

### users
```sql
id            uuid PK default gen_random_uuid()
phone         text UNIQUE NOT NULL          -- E.164, verified
name          text NOT NULL
photo_url     text
gender        text CHECK (gender IN ('female','male','other')) NULL
home_region_id uuid REFERENCES regions NOT NULL
women_only    boolean NOT NULL DEFAULT false  -- passenger preference
status        text NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended','deleted'))
created_at / updated_at timestamptz
```

### driver_profiles
```sql
user_id       uuid PK REFERENCES users
car_model     text NOT NULL
car_color     text
car_plate     text NOT NULL                 -- shown only post-accept
fuel_consumption_l_100km numeric(4,1) NOT NULL DEFAULT 7.0
wear_factor   numeric(3,2) NOT NULL DEFAULT 1.0 CHECK (wear_factor BETWEEN 1.0 AND 1.5)
free_below_km numeric(4,1) NOT NULL DEFAULT 5.0
notify_radius_km numeric(4,1) NOT NULL DEFAULT 2.0
detour_budget_min int NOT NULL DEFAULT 10 CHECK (detour_budget_min BETWEEN 0 AND 30)
notifications_muted boolean NOT NULL DEFAULT false
```

### regions
```sql
id       uuid PK
name     text NOT NULL                      -- e.g. "Έβρος"
boundary geometry(MultiPolygon,4326) NOT NULL
fuel_price_eur numeric(4,3) NOT NULL        -- admin-updated
GIST index on boundary
```

### route_templates  (a driver's published route)
```sql
id            uuid PK
driver_id     uuid REFERENCES driver_profiles NOT NULL
origin        geometry(Point,4326) NOT NULL
destination   geometry(Point,4326) NOT NULL
origin_label / destination_label text NOT NULL
route_geom    geometry(LineString,4326) NOT NULL  -- OSRM-snapped polyline
route_km      numeric(6,1) NOT NULL
route_min     int NOT NULL                        -- baseline duration
seats         int NOT NULL DEFAULT 3 CHECK (seats BETWEEN 1 AND 8)
pricing_mode  text NOT NULL DEFAULT 'formula' CHECK (pricing_mode IN ('formula','free_contribution','free'))
osrm_data_version text NOT NULL
active        boolean NOT NULL DEFAULT true
created_at / updated_at

GIST index on route_geom
-- Buffered-geometry functional index for the gross match (see MATCHING.md):
CREATE INDEX route_templates_buffer_gist ON route_templates
  USING GIST (ST_Buffer(route_geom::geography, 3000)::geometry);
-- 3000 m = max supported notify_radius (per-driver radius applied as a filter after)
```

### route_schedules  (recurrence rule for a template; one-off = single date)
```sql
id             uuid PK
template_id    uuid REFERENCES route_templates UNIQUE NOT NULL
kind           text NOT NULL CHECK (kind IN ('oneoff','recurring'))
oneoff_date    date NULL                     -- kind = oneoff
weekdays       int[] NULL                    -- kind = recurring, ISO 1..7
depart_earliest time NOT NULL               -- local Europe/Athens
depart_latest   time NOT NULL
effective_from  date NOT NULL DEFAULT current_date
effective_until date NULL
exceptions      date[] NOT NULL DEFAULT '{}' -- skipped dates
```

### trip_occurrences  (materialized concrete trips — matching runs on THESE)
Generated by the materializer over a rolling 3-week horizon; regenerated on
template/schedule edit (future, unbooked ones only).

An edit (`PUT /v1/me/routes/{id}`) changes the template in place and bumps
`revision`. A departure with a confirmed booking or a pending ask keeps its
time, seats and price; the rest take the new terms. The ends cannot change in
an edit (409 `route_ends_changed`): that is a new route. A driver who calls
off one departure also adds its date to `exceptions`, so the materializer does
not put it back.
```sql
id             uuid PK
template_id    uuid REFERENCES route_templates NOT NULL
depart_earliest timestamptz NOT NULL        -- concrete instants (DST-safe)
depart_latest   timestamptz NOT NULL
seats_total    int NOT NULL
seats_free     int NOT NULL
status         text NOT NULL DEFAULT 'scheduled'
               CHECK (status IN ('scheduled','started','completed','cancelled'))
itinerary_version int NOT NULL DEFAULT 0    -- bumps on each accepted booking
UNIQUE (template_id, depart_earliest)
index on (status, depart_earliest)
```

### ride_requests  (passenger side)
```sql
id            uuid PK
passenger_id  uuid REFERENCES users NOT NULL
origin        geometry(Point,4326) NOT NULL
destination   geometry(Point,4326) NOT NULL
origin_label / destination_label text
window_start / window_end timestamptz NOT NULL
seats         int NOT NULL DEFAULT 1
kind          text NOT NULL CHECK (kind IN ('open','targeted'))
target_occurrence_id uuid REFERENCES trip_occurrences NULL  -- kind = targeted
status        text NOT NULL DEFAULT 'open'
              CHECK (status IN ('open','asking','matched','expired','cancelled'))
created_at
GIST indexes on origin, destination; index on (status, window_end)
```

### asks  (one driver being asked about one request — sequential)
```sql
id             uuid PK
request_id     uuid REFERENCES ride_requests NOT NULL
occurrence_id  uuid REFERENCES trip_occurrences NOT NULL
detour_min     numeric(4,1) NOT NULL         -- computed at ask time
detour_km      numeric(5,1) NOT NULL
pickup_point   geometry(Point,4326) NOT NULL -- snapped to driver route
dropoff_point  geometry(Point,4326) NOT NULL
suggested_price_eur numeric(5,2) NOT NULL
status         text NOT NULL DEFAULT 'pending'
               CHECK (status IN ('pending','accepted','declined','expired','cancelled'))
expires_at     timestamptz NOT NULL
created_at
-- exactly one live ask per request:
CREATE UNIQUE INDEX asks_one_pending ON asks(request_id) WHERE status = 'pending';
```

### bookings  (accepted ask → seat on an occurrence)
```sql
id             uuid PK
occurrence_id  uuid REFERENCES trip_occurrences NOT NULL
request_id     uuid REFERENCES ride_requests NOT NULL
passenger_id   uuid REFERENCES users NOT NULL
ask_id         uuid REFERENCES asks NOT NULL
seats          int NOT NULL
price_eur      numeric(5,2) NOT NULL         -- suggestion frozen at accept
status         text NOT NULL DEFAULT 'confirmed'
               CHECK (status IN ('confirmed','cancelled_by_passenger',
                                 'cancelled_by_driver','completed','no_show'))
driver_confirmed / passenger_confirmed boolean NOT NULL DEFAULT false
UNIQUE (occurrence_id, passenger_id)
```

### ratings
```sql
id          uuid PK
booking_id  uuid REFERENCES bookings NOT NULL
rater_id / ratee_id uuid REFERENCES users NOT NULL
stars       int NOT NULL CHECK (stars BETWEEN 1 AND 5)
tag         text NULL                        -- 'punctual','friendly',...
UNIQUE (booking_id, rater_id)
```

### outbox  (see ARCHITECTURE.md)
```sql
id           bigserial PK
kind         text NOT NULL      -- 'push','ws','ask_next','materialize',...
payload      jsonb NOT NULL
idempotency_key text UNIQUE NOT NULL
run_after    timestamptz NOT NULL DEFAULT now()
attempts     int NOT NULL DEFAULT 0
locked_until timestamptz NULL
done_at      timestamptz NULL
last_error   text NULL
index on (done_at, run_after) WHERE done_at IS NULL
```


## Retention / privacy

- Raw location data: only trip endpoints and published routes are persisted.
  Live positions are ephemeral (single upserted row, deleted at trip end).
- Completed trips: keep 12 months, then anonymize (drop precise points, keep stats).
- Deleted account: rows anonymized, phone hash kept 6 months for ban evasion.
